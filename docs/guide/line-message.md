# ข้อความ LINE สำหรับส่งให้ผู้ใช้

## ข้อความที่ 1: ติดตั้ง

```
สวัสดีครับ ส่งแดชบอร์ดหุ้นไทย SET100 มาให้ลองใช้ครับ
ดูหุ้นในพอร์ต ปันผล เกรดความปลอดภัยของปันผล และปฏิทินเงินปันผลรายเดือน ใช้ฟรี ทำงานในคอมพิวเตอร์ของเราเอง

วิธีติดตั้ง (ให้ Claude พาทำทีละขั้น):
1. เปิดลิงก์นี้ในคอมพิวเตอร์ https://github.com/STeerajit/stock-dashboard/blob/feat/income-calendar/docs/guide/setup-assistant.md
2. กดปุ่ม "Copy raw file" (รูปกระดาษซ้อนกัน มุมขวาบนของกรอบข้อความ)
3. เปิด claude.ai หรือแอป Claude เริ่มแชตใหม่ คลิกในช่องพิมพ์ กด Ctrl+V แล้วกดส่ง
4. ทำตามที่ Claude บอกทีละขั้น เมื่อ Claude ขอภาพหน้าจอ ให้กด Windows+Shift+S ลากคลุมหน้าจอ แล้วกด Ctrl+V ในแชต แล้วส่ง

ใช้เวลาประมาณ 30-45 นาที ต้องต่อเน็ต ติดตรงไหนถ่ายภาพส่งมาได้เลยครับ
เพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุนนะครับ
```

## ข้อความที่ 2: วิธีใช้ (ส่งหลังติดตั้งเสร็จ)

```
ติดตั้งเสร็จแล้ว อยากรู้ว่าแต่ละหน้าหรือตัวเลขหมายถึงอะไร ทำแบบเดิมครับ:
1. เปิดลิงก์ https://github.com/STeerajit/stock-dashboard/blob/feat/income-calendar/docs/guide/app-assistant.md
2. กดปุ่ม "Copy raw file" มุมขวาบน
3. วางในแชต Claude ห้องใหม่ แล้วถามได้เลย ส่งภาพหน้าจอประกอบได้
ข้อควรจำ: ราคาช้าประมาณ 15 นาที และข้อมูลอาจผิดได้ ก่อนซื้อขายให้ตรวจที่ set.or.th และแอปโบรกเกอร์ครับ
```
